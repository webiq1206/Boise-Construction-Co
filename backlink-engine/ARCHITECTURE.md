# Free-only Construction growth architecture

1. Validate the fixed Construction identity before processing inputs.
2. Import at most 100 known public URLs or explicitly identified manual Search Console Links-export rows.
3. Preserve existing source-level identity, review, suppression, pending state and receipts when deduplicating.
4. Hold unknown editorial fit, unverified routes, paid opportunities and ineligible listings. Report unobserved metrics as null.
5. Prepare Construction-only artifacts locally. Every draft carries unresolved dispatch/suppression/capacity and action-authorization gates.
6. Write ignored local state only when requested; dry-run has no writes.

The engine imports no paid API client, contact crawler, database adapter or send provider. The legacy dispatch command remains unconditionally paused. The existing P5 free-growth owner retains all live work and schedule responsibility.

Historical copied Remodeling material is quarantined, not relabeled as Construction history. Live verification, durable shared-ledger concurrency, failure recovery, sender/suppression/capacity acceptance and production qualification are subsequent release gates. No autonomous acquisition or traffic outcome is claimed here.
